## Decisao

Nao promover a v1 para o MCT.

A proxima versao deve atacar o erro de formulacao, nao apenas ajustar
hiperparametros. O alvo passa a representar um primeiro evento de virada perto
de uma maxima, com treinamento condicionado a regime de alta e proximidade do
topo, calibracao orientada a precisao e confirmacao temporal antes da saida.
