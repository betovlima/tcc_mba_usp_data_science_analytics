# v1.2.0-dev.4 — nomes de metodos de execucao em portugues

## Contexto

O arquivo `engine/execution.py` ainda mantinha nomes de funcoes em ingles,
apesar de ser codigo interno do projeto e nao uma API externa.

## Alteracao

As funcoes foram renomeadas:

- `round_fee_to_cent` -> `arredondar_taxa_para_centavo`;
- `calculate_reference_fees` -> `calcular_taxas_referencia`;
- `apply_slippage` -> `aplicar_deslizamento`.

As chamadas em `reproducao/experimento.py` foram atualizadas para usar os
novos nomes.

Campos de dados, nomes de bibliotecas, constantes de mercado e contratos
externos permanecem inalterados quando a traducao poderia prejudicar
compatibilidade ou clareza tecnica.

## Impacto

A mudanca e apenas estrutural e de legibilidade. Nao altera calculo de taxas,
slippage, estrategia, dados, folds ou resultados esperados do experimento.

## Testes

Foi adicionado teste que exige os novos nomes em portugues e impede o retorno
dos tres nomes antigos em ingles.
