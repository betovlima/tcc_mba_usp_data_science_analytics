(Tiingo, MongoDB, referencia de 43M, CARO, tuning e diagnosticos).

Eles nao fazem parte da reproducao oficial v1.0.0.

O caminho oficial e:

```text
reproduzir_experimento_spyder.py
reproducao/
tcc_engine/
dados/reproducao_v1/
output/reproducao_v1/
```

Os arquivos foram mantidos apenas para rastreabilidade historica e comparacao
com etapas anteriores da pesquisa.
