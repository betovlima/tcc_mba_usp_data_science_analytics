# TCC v1.2.0-dev.10 — Switch-margin calibration audit

## Context

The latest TCC Control execution and the current MCT Strategy #11 use the same
base switch margin and the same calibration candidates:

- base margin: `0.0005`
- candidates: `0.0, 0.0025, 0.005, 0.01`

The first material out-of-sample divergence observed between both projects occurs
in fold 1. At that point the model utilities can be equal while the selected
calibrated switch margin differs. This makes the fold calibration step the next
scientific object to audit.

## Version and branch

- experiment version: `1.2.0-dev.10`
- branch: `research/tcc-v1.2.0-dev.10-switch-margin-calibration-audit`

through 2026-09-17. A local temporary execution with newer data is not promoted
to the scientific snapshot by this change.

## Change

For every walk-forward fold and every candidate switch margin, the engine now
records:

- `margin`
- `risk_adjusted_score`

It also records, per fold:

- `calibrated_candidate_margin`
- `effective_switch_margin`
- `calibration_risk_adjusted_score`
- `calibration_candidate_scores`
- `calibration_score_gap_best_vs_second`

The technical log emits an explicit line:

`event=switch_margin_calibration`

with all candidate scores, selected candidate, base margin, effective margin and
best-vs-second gap.

## Output

A new file is generated under `output/reproducao`:

`switch_margin_calibration.csv`

It contains one row per variant, fold and candidate, making the TCC output
directly comparable with the MCT calibration diagnostics.

The enriched calibration fields are also preserved inside the fold metrics in
`summary.json`.

## Scientific purpose

The next run should answer one specific question:

> Why does fold 1 select a different switch margin between the TCC and MCT?

If the four candidate scores differ, the investigation moves upstream to the
calibration window, fitted model predictions or calibration transition rewards.

If the four candidate scores are equal but the selected margin differs, the
selection/tie-breaking implementation is the source of the divergence.
